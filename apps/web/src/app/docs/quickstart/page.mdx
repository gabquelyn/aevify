# Quickstart

Take your first tUSD8 payment on Aevum in about five minutes.

## 1. Set up your account

1. [Sign in](/signin) with Google or an email link, and name your business.
2. In **Settings**, click **Connect wallet**. Your wallet signs a free message proving you own it,
   and Aevify registers it on the contract. Payments settle to this wallet.
3. In **Developers**, click **Create secret key** and copy it. It's shown only once.

Your wallet needs to be on Aevum: see [Aevum testnet](/docs/testnet) for adding the network
and getting test tokens.

## 2. Create a payment

From your server (or a terminal), with your Aevify app's URL as `AEVIFY_BASE_URL`:

```bash
curl -X POST "$AEVIFY_BASE_URL/api/v1/payments" \
  -H "Authorization: Bearer $AEVIFY_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: order-1042" \
  -d '{ "amount": "2.50", "orderId": "1042", "description": "Coffee beans" }'
```

The response is a [payment object](/docs/api#payment-object) with a `checkoutUrl`.

Or with the Node SDK:

```ts
import { Aevify } from "@aevify/node";

const aevify = new Aevify(process.env.AEVIFY_SECRET_KEY!, { baseUrl: process.env.AEVIFY_BASE_URL });
const payment = await aevify.payments.create({ amount: "2.50", orderId: "1042" });
console.log(payment.checkoutUrl);
```

## 3. Pay it

Open `checkoutUrl` in a browser with a wallet on Aevum, connect, and pay. The checkout switches
the wallet to Aevum, checks the balance, and pays in one step when the token supports permits
(otherwise approve, then pay).

## 4. See it paid

```bash
curl "$AEVIFY_BASE_URL/api/v1/payments/pay_..." -H "Authorization: Bearer $AEVIFY_SECRET_KEY"
```

`status` is now `paid`, with `paidBy`, `fee` and `txHash`. The payment also appears in the
dashboard, with a link to the transaction on the Aevum explorer.

**No code at all?** In the dashboard, **Payments → New payment link** creates the same thing.
